# Orbita 🌱

Petit jeu mobile à une touche (HTML5, un seul fichier, aucune dépendance).

**But :** une planète tourne. Touche l'écran pour lancer une pousse qui se plante dessus.
Si elle touche une pousse déjà plantée, c'est raté. Plante-les toutes et la planète fleurit.

- **Des planètes vivantes** : chacune a un visage, un caractère et réagit à ce que tu fais.
- **Des humeurs** : la planète annonce avec son visage ce qu'elle va faire (changer de sens, sprinter, s'endormir…). Savoir la lire, c'est gagner.
- **8 mondes** de 5 niveaux, chacun avec son boss à apprivoiser, puis des variantes sans fin.
- **3 étoiles par niveau** : finir le niveau, plus deux étoiles à cueillir.
- Difficulté rééquilibrée : jamais plus de 14 pousses sur la planète, la difficulté vient du rythme.
- Progression sauvegardée, sons générés, vibrations, installable sur l'écran d'accueil (PWA, hors-ligne).

## Jouer

Ouvre `index.html` dans un navigateur. Pour jouer sur téléphone, active **GitHub Pages**
(Settings → Pages → branche, dossier `/`), ouvre l'adresse sur ton mobile, puis fais
« Ajouter à l'écran d'accueil ».
