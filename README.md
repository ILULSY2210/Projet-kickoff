# Orbita 🪐

Petit jeu mobile (HTML5, un seul fichier, aucune dépendance).

**But :** une planète tourne. Touche l'écran pour lancer une flèche qui se plante dedans.
Si ta flèche touche une flèche déjà plantée, c'est raté. Plante toutes tes flèches pour passer au niveau suivant.

- Niveaux infinis, de plus en plus durs (vitesse, changements de sens, accélérations, flèches déjà plantées)
- Un **BOSS** tous les 5 niveaux
- ★ Étoiles bonus à toucher pour obtenir 3 étoiles par niveau
- Progression sauvegardée sur le téléphone, sons et vibrations
- Installable sur l'écran d'accueil (PWA, fonctionne hors-ligne)

## Jouer

Ouvre `index.html` dans un navigateur. Pour jouer sur téléphone, active **GitHub Pages**
(Settings → Pages → branche, dossier `/`) puis ouvre l'adresse sur ton mobile et fais
« Ajouter à l'écran d'accueil ».
